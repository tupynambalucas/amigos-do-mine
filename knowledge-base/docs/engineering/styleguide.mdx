# Guia de Estilo e Padrões

Este documento define as convenções estritas de codificação e requisitos de qualidade para o projeto **Amigos Do Mine**. Estas regras são obrigatórias para todos os assistentes de IA e contribuidores humanos.

---

## 1. As Diretrizes Primárias 🛡️

*   **SSOT ou Morte**: Nunca use `any`. Todas as formas de dados devem vir de `@amigos-portal/core`. Se um tipo estiver faltando, crie-o lá primeiro.
*   **Segurança de Ativos**: Não toque em ativos brutos em `portal/apps/api`. Sempre edite em `resources/` e use o pipeline de build.
*   **Async Everything**: Todas as operações de I/O (leitura de arquivos, requisições web, consultas ao banco) DEVEM ser assíncronas. Bloquear a thread principal (especialmente no servidor de jogo) é estritamente proibido.
*   **Inglês Técnico**: Todo o código, comentários e documentação técnica devem estar em Inglês.

## 2. Regras de TypeScript e Codificação Geral

Priorizamos a máxima segurança de tipos através de uma configuração rigorosa de TypeScript.

- **Definições de Objetos:** Use `interface` para definições de objetos. Use aliases de tipo para uniões ou tipos utilitários.
- **Importação de Tipos:** Sempre use `import type` para tipos.
- **Booleanos Estritos:** Expressões booleanas devem ser explícitas. Use `if (value !== undefined)` em vez de `if (value)`.
- **Comparações:** Sempre use igualdade estrita (`===`).
- **Convenções de Nomenclatura**:
    - **Schemas:** Devem terminar com `Schema` (ex: `UserSchema`).
    - **Arquivos:** Seguir o padrão `nome.tipo.ts` (ex: `auth.controller.ts`).
    - **Diretórios:** Usar `camelCase`.

## 3. Minecraft e Recursos 🎨
(`resources/`)

- **Nomenclatura**: Use `snake_case` para arquivos de ativos (ex: `ruby_sword.png`).
- **Organização**: Mantenha texturas em `/textures` e modelos em `/models`.
- **Exportação**: Sempre use o script de build para empacotar os resource packs.

## 4. Docker e Infraestrutura 🐳

- **Permissões de Usuário**: Em produção, os serviços rodam como um usuário restrito (ex: `user: minecraft`).
- **Shutdown Gracioso**: Use a forma `exec` nos Dockerfiles para garantir que os sinais SIGTERM sejam tratados.
- **Rebuilds**: Rode com `--build` sempre que a configuração de infraestrutura (como `eudev-libs`) for modificada.

## 5. Princípios SOLID 🧱

Construímos para o futuro. Código espaguete é proibido.

- **S**ingle Responsibility: Uma classe, uma função.
- **O**pen/Closed: Estenda a funcionalidade, não a reescreva.
- **L**iskov Substitution: Subtipos devem se comportar como seus pais.
- **I**nterface Segregation: Mantenha as interfaces pequenas e focadas.
- **D**ependency Inversion: Dependa de abstrações, não de concreções.

### 6.1. Exemplo de Padrão Rigoroso

```jsx live
/**
 * Exemplo de Gestor de Estado Avançado
 * Demonstra: Interfaces, useCallback, operador void e booleanos explícitos.
 */

function ServerStatsManager() {
  const [servers, setServers] = React.useState([
    { id: 'lobby-1', status: 'online', players: 42 },
    { id: 'survival-1', status: 'manutencao', players: 0 },
  ]);
  const [isRefreshing, setIsRefreshing] = React.useState(false);

  const hasIssues = React.useMemo(() => {
    return servers.some((s) => s.status === 'manutencao');
  }, [servers]);

  const refreshData = async () => {
    setIsRefreshing(true);
    try {
      await new Promise((resolve) => setTimeout(resolve, 1000));
      console.info('Stats atualizados');
    } finally {
      setIsRefreshing(false);
    }
  };

  const handleAction = () => {
    void refreshData();
  };

  return (
    <div style={{ padding: '1rem', border: '1px solid #ccc', borderRadius: '8px' }}>
      <h3>Monitor de Servidores</h3>
      <div style={{ marginBottom: '1rem' }}>
        {hasIssues === true ? '⚠️ Problemas Detectados' : '✅ Sistemas Operantes'}
      </div>
      <button 
        disabled={isRefreshing === true}
        onClick={handleAction}
        style={{ cursor: isRefreshing === true ? 'not-allowed' : 'pointer' }}
      >
        {isRefreshing === true ? 'Atualizando...' : 'Forçar Atualização'}
      </button>
    </div>
  );
}
```
