# Visão de Produto

O **Amigos Do Mine** não é apenas um servidor de Minecraft; é toda uma experiência. 🌟

Estamos construindo um ecossistema que une a criatividade em blocos do Minecraft com a performance ágil da web moderna. Nosso objetivo? Criar um servidor que pareça menos com uma "sopa de plugins" e mais com uma experiência de estúdio de jogo polida e independente.

---

## 1. A Grande Visão 🚀

Queremos fechar o abismo. Geralmente, servidores de Minecraft e seus sites parecem dois estranhos morando em casas diferentes. Nós estamos mudando eles para a mesma residência.

*   **Para os Jogadores:** É fluido. Você entra, as texturas customizadas carregam sozinhas, seu perfil web sincroniza instantaneamente e a economia simplesmente funciona.
*   **Para os Admins:** É um superpoder. Você tem um dashboard em React 19 que te dá controle total sobre o servidor, logs e economia de qualquer lugar.

---

## 2. Funcionalidades Core ✨

### 2.1. Experiência do Jogador
*   **Imersão Total**: Não usamos apenas itens vanilla. Temos um pipeline para modelos 3D e texturas customizadas entregues diretamente ao jogador.
*   **Portal Web**: Confira seus stats, compre itens na loja ou gerencie seu perfil sem nem abrir o launcher do jogo.
*   **Uma ID para Todos**: Seu login web e seu UUID do Minecraft são melhores amigos.

### 2.2. Poderes de Admin
*   **Centro de Comando**: Um dashboard lindo construído com React 19. Chega de forçar a vista em logs de terminal.
*   **Pipeline "Studio"**: Temos um workspace dedicado para criação de ativos. Você constrói, nós implantamos, e cada jogador recebe a atualização automaticamente.

---

## 3. Identidade Visual & Tema 😎

1.  **Onboarding Mágico**: Conecte e jogue. Os resource packs se resolvem sozinhos via nosso pipeline automatizado no backend.
2.  **Consistência Visual**: Mantemos uma linguagem de design unificada entre o jogo e a web.
3.  **Velocidade**: Priorizamos TPS alto e APIs de baixa latência. Ninguém gosta de lag.
