# ⚡ Cheat Sheet Rápido

Uma referência abrangente para desenvolvedores gerenciarem o monorepo **Amigos Do Mine**, infraestrutura e automação.

---

## 🎮 Servidor de Jogo (Minecraft)

Gestão do container do servidor Purpur.

- **Iniciar Servidor:** `pnpm server:up`
- **Parar Servidor:** `pnpm server:down`
- **Ver Logs:** `pnpm server:logs`
- **Reiniciar Servidor:** `pnpm server:restart`
- **Resetar Dados:** `pnpm server:reset` (Remove e recria o container)
- **Anexar Console:** `pnpm server:attach` (Pressione `Ctrl+P, Ctrl+Q` para desanexar)

---

Executando a infraestrutura web.

<Tabs>

    - **Build:** `pnpm --filter @amigos-portal/api build`
  </TabItem>
  <TabItem value="docs" label="Documentação">
    - **Iniciar Docusaurus:** `pnpm dev:docs`
    - **Build da Docs:** `pnpm build` (Executa build para todos os workspaces)
  </TabItem>

---

## 🛠️ Ativos & Plugins (Resources)

Construindo conteúdo customizado para o jogo.

- **Build do Amigos Plugin:** `pnpm build:plugin`
- **Build do Resource Pack:** `pnpm build:resourcepack`

---

## 📦 Gestão de Workspace

Lidando com dependências internas e qualidade.

- **Limpar node_modules:** `pnpm clean:project`
- **Validar Tipagem (Typecheck):** `pnpm typecheck`
- **Lint:** `pnpm lint`

---

## 🎨 Studio & Design (Penpot)

Orquestrando o ambiente de design self-hosted.

- **Iniciar Penpot:** `pnpm penpot:up`
- **Parar Penpot:** `pnpm penpot:down`
- **Ponte Aide AI:** `pnpm penpot:aide:up` / `pnpm penpot:aide:down`
