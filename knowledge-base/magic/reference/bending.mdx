# Bending Configs

![Bending](http://i.imgur.com/nXVOV3Q.png)

## Using

Simply use the following command to enable these configs:

`/mconfig example set bending`

Use `/mnpc add bendingshop` to add an NPC that will teach you one of four bending styles.

You can also use `/cast bendingshop` to quickly test out the shop.

You can only choose an element once, and will have to `/mage reset` yourself or others if you want to switch.

## Customizing

Changes to the customized configs in plugins/Magic will affect example configurations as normal. Example configs are fully customizable.

## Configuration

If you'd like to see the bending configs, look here:

https://github.com/elBukkit/MagicPlugin/tree/master/Magic/src/main/resources/examples/bending

You won't be able to find them on your server, they are built into the plugin and not saved anywhere to disk.
