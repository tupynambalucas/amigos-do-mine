# Essentials Integration

To sell a wand or spell on an Essentials shop sign, use the following
format:

```text
"wand: <name>"
"wand: elder" 
or 
"spell: <name>",
"spell: blink"
```

Use this as you would any other item name. You may also include wands in
kits the same way.

Magic allows Essentials warps to be used in the [Recall](../reference/recall.mdx) spell for waypoints.
