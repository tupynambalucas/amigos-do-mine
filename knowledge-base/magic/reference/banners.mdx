# Banner Configs

## Using

Simply use the following command to enable these configs:

`/mconfig example add banners`

Use `/mnpc add bannershop` to add an NPC that will sell a bunch of custom banners.

That's basically it. These would simply be included in the survival example, but they have backwards-compatibility issues, and so this example should only be used in 1.14 and up.
