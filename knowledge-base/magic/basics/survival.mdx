---
title: Survival
---

Survival is the default example that is enabled when you drop Magic in.

It is meant to be an extension to the vanilla survival experience, letting players acquire and level up a set of spells and other items, without any other server setup required.

Wands can be crafted, and spells can be purchased by right-clicking an enchantment table with a wand.

Spells are purchased using spell points, which are earned by casting spells.

Many spells level up, this is also done just by casting the spells.
