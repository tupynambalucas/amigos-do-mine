### Installation

Magic requires [Spigot](http://www.spigotmc.org) or CraftBukkit, just place Magic.jar into the plugins
folder. This is all you need to do to experiment with spells, by default
only ops can get wands (though anyone can cast any spells if they get
ahold of a wand with spells!)

### Permissions

By default only op's have access to any commands, players do not need commands to use Magic and generally should not have any.

[See All Permissions](../basics/permissions.mdx)

### Commands

Commands in Magic are generally for admin-use only. 

[See All Commands](../basics/commands.mdx)
