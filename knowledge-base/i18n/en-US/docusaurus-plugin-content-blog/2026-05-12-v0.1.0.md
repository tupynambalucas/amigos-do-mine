Welcome to the foundation of **Amigos Do Mine** (v0.1.0)! 🎉

This release marks the official initialization of our ecosystem, establishing a professional-grade engineering foundation for our Minecraft server and web platform. We've focused on building a scalable monorepo that bridges the gap between game customization and modern web development.

{/* truncate */}

### 🏗️ Monorepo Architecture
- **Unified Workspace**: Implemented **PNPM Workspaces** and **Turborepo** to manage our entire stack in a single, high-performance repository.
- **Strict Typing**: Established a "Zero Tolerance for `any`" policy with TypeScript, ensuring type safety across the board.
- **Context Separation**: Organized the project into clear bounded contexts: `/portal`, `/minecraft`, `/resources`, `/studio`, and `/tools`.

### 🎮 Minecraft Foundation
- **Purpur 1.21+**: Initialized a high-performance Purpur server environment.
- **Dockerized Infrastructure**: Fully containerized the server for consistent development and deployment workflows.
- **Custom Pipeline**: Established the development workflow for the **Amigos Plugin** (Kotlin) and the custom **Resource Pack** (MCreator assets).

### 🌐 Web & API Infrastructure
- **Portal Core**: Scaffolded the React 19 frontend and Fastify 5 backend architectures.
- **Design System (Studio)**: Initialized our design tokens and branding assets using Nunito typography and a custom color palette.
- **Documentation**: Launched this Docusaurus-powered **Knowledge Base** to serve as our central source of truth for engineering and product vision.

### 🤖 Automation & DX
- **CI/CD Ready**: Configured GitHub Actions for automated documentation deployment and changelog generation.
- **Developer Tools**: Integrated MCP (Model Context Protocol) servers to enhance AI-assisted development.

This is just the beginning. The foundation is laid, and the "magic" is about to start!
