# ⚡ Quick Cheat Sheet

A comprehensive reference for developers to manage the **Amigos Do Mine** monorepo, infrastructure, and automation.

---

## 🎮 Game Server (Minecraft)

Management of the Purpur server container.

- **Start Server:** `pnpm server:up`
- **Stop Server:** `pnpm server:down`
- **View Logs:** `pnpm server:logs`
- **Restart Server:** `pnpm server:restart`
- **Reset Data:** `pnpm server:reset` (Wipes and recreates container)
- **Attach Console:** `pnpm server:attach` (Press `Ctrl+P, Ctrl+Q` to detach)

## 🛠️ Assets & Plugins (Resources)

Building custom game content.

- **Build Amigos Plugin:** `pnpm build:plugin`
- **Build Resource Pack:** `pnpm build:resourcepack`

---

## 📦 Workspace Management

Handling internal dependencies and quality.

- **Clean node_modules:** `pnpm clean:project`
- **Typecheck All:** `pnpm typecheck`
- **Lint All:** `pnpm lint`

## 🎨 Studio & Design (Penpot)

Orchestrating the self-hosted design environment.

- **Start Penpot:** `pnpm penpot:up`
- **Stop Penpot:** `pnpm penpot:down`
- **Aide AI Bridge:** `pnpm penpot:aide:up` / `pnpm penpot:aide:down`
