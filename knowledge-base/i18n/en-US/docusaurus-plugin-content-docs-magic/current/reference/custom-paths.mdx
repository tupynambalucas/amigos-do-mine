# Customizing Progress via Paths

A "Path" in Magic is a collection of ranks. A wand may be at a certain rank on that path, and will progress along the path from rank to rank.

Paths are defined in `paths.yml`, new paths can be added there or default paths modified.

Paths have lists of spells available for each rank, as well as other properties like mana benefits, special effects used when ranking up, and more.

Detailed documentation may be added here eventually, for now please refer to the well-documented survival paths:
