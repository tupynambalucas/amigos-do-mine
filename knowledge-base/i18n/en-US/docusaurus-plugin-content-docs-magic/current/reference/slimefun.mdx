## Using the Slimefun example

If you also use Slimefun, you can turn on the slimefun example in Magic to use a merged resource pack. It is based on this one:

https://www.planetminecraft.com/texture-pack/slimefun-texture-by-raulh22/

Use `/mconfig example set slimefun` to turn this on.

Note that this resource pack does not get automatically updated, but I will do my best to keep it current. Come bug me on Discord if this is something you use and it's missing some newer icons!

Also note that there are some items in the `item-models.yml` that do not actually have an appearance in the Slimefun RP. These will need to be removed from the yml file or they will show up incorrectly in Slimefun. 

These items seem to be the multi-tool items, but you may have to experiment and see. This may or may not be a complete list (Thanks, Renzotom!)

ENDER_HELMET: 0
SLIME_HELMET: 0
MAGICAL_BOOK_COVER: 0
GLOWSTONE_HELMET: 0
CACTUS_HELMET: 0
DURALUMIN_MULTI_TOOL: 0
