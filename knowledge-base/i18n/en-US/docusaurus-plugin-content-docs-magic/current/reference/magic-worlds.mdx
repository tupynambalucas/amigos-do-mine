---
title: Magic Worlds
---

Magic can create customized worlds. The magic editor can make this process easy, for instance to start creating a new world use `/meditor world newworld`.

There are a few builtin examples that demonstrate how these custom worlds can change block generation or mob spawning:

* [The Nether Side](the-nether-side.mdx)
* [The Other Side](the-other-side.mdx)
