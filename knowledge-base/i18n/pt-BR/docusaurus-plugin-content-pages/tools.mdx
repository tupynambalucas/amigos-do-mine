<div className="container margin-vert--lg">
  <h1>Workspace de Ferramentas (Tools)</h1>

  <p>O workspace Tools fornece a espinha dorsal de automação para o projeto Amigos Do Mine. Ele centraliza servidores especializados de Model Context Protocol (MCP) e scripts de infraestrutura projetados para aumentar a produtividade do desenvolvedor e garantir a paridade de ambiente.</p>

  <Tabs>
    <TabItem value="mcp" label="Ecossistema MCP" default>
      <h3>Infraestrutura Model Context Protocol</h3>
      <p>O projeto utiliza uma rede de servidores MCP especializados. Esses servidores atuam como provedores de contexto estruturado, permitindo que agentes de IA interajam de forma segura e precisa com as camadas de dados do projeto e APIs de infraestrutura.</p>

      <h4>Servidores de Contexto Integrados</h4>

      - **GitHub MCP:** Gerencia a orquestração do repositório e análise de Pull Requests.
      - **Context7 MCP:** Uma ponte de pesquisa para busca de documentação técnica em tempo real.
      - **Docker Hub MCP:** Gerencia a descoberta e sincronização de imagens de container.
    </TabItem>

    <TabItem value="network" label="Segurança de IA & Rede">
      <h3>Arquitetura de Infraestrutura Isolada</h3>
      <p>A segurança é mantida através de um modelo de rede zero-trust para agentes de IA. As ferramentas de automação operam dentro de um ambiente Docker isolado.</p>

      <h4>Topologia de Rede</h4>

      - **Ponte Privada (Private Bridge):** Todos os serviços MCP comunicam-se através de uma rede dedicada.
      - **Segurança de Recursos:** Dockerfiles multi-estágio garantem que apenas os binários necessários sejam incluídos.
    </TabItem>

    <TabItem value="guidelines" label="Diretrizes de Engenharia">
      <h3>Regras de Engajamento para Agentes de IA</h3>
      <p>O workspace define a lógica comportamental estrita para agentes de IA.</p>

      <h4>Convenções Operacionais</h4>

      - **Domain Core First:** A modificação de esquemas compartilhados deve originar-se no pacote `@amigos-portal/core`.
      - **Tipagem Estrita:** Agentes estão proibidos de usar `any` ou ignorar configurações de TypeScript/ESLint.
      - **Validação:** A execução do `pnpm typecheck` é obrigatória após qualquer modificação.
    </TabItem>

    <TabItem value="scripts" label="Manutenção">
      <h3>Lógica Operacional e Manutenção</h3>
      <p>Comandos padronizados são fornecidos para a manutenção do workspace em todo o monorepo.</p>

      <table>
        <thead>
          <tr>
            <th>Comando</th>
            <th>Responsabilidade de Engenharia</th>
          </tr>
        </thead>
        <tbody>
          <tr>
            <td><code>pnpm typecheck</code></td>
            <td>Valida a integridade do TypeScript em todo o workspace.</td>
          </tr>
          <tr>
            <td><code>clean:project</code></td>
            <td>Manutenção do workspace usando <code>npkill</code>.</td>
          </tr>
        </tbody>
      </table>
    </TabItem>
  </Tabs>
